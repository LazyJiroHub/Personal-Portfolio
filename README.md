# Personal Portfolio Website

A responsive personal portfolio website that presents my profile, skills, projects, education, achievements, and contact information.

**Live site:** https://xyrusbanal.github.io/personal-portfolio/
**Repository:** https://github.com/xyrusbanal/personal-portfolio

> Replace `xyrusbanal` above with your actual GitHub username.

## Project Overview

This project is a single-page portfolio built for the Personal Website Portfolio Performance Task. It is designed to be clean, readable, and usable on desktop, tablet, and mobile.

## Technologies Used

- **HTML5** – semantic structure (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS3** – custom properties (variables), Flexbox, CSS Grid, transitions, media queries
- **JavaScript (vanilla)** – DOM manipulation, event listeners, IntersectionObserver, localStorage
- **Git & GitHub** – version control
- **GitHub Pages** – deployment
- **Google Fonts** – Inter and Space Grotesk

## Features

- Sections: Home, About Me, Skills, Projects, Education & Achievements, Contact, Footer
- Responsive layout with breakpoints at 900px, 768px, and 480px
- Hamburger menu on mobile
- Dark / light mode toggle (remembers your choice)
- Typing animation in the headline
- Active navigation link highlighting while scrolling
- Scroll-reveal animations and animated skill bars
- Project filter buttons (All / Websites / Web Apps)
- Contact form with JavaScript validation
- Copy-email button and back-to-top button

## Setup / Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/xyrusbanal/personal-portfolio.git
   ```
2. Open the folder and double-click `index.html`, or use the **Live Server** extension in VS Code.

No installation or build step is needed.

## Deployment (GitHub Pages)

1. Push all files to the `main` branch of a public repository.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.
4. Wait 1–2 minutes and open the live URL shown on that page.
